# 💰 Sistema de Controle Financeiro

Um sistema desenvolvido em Python para auxiliar no controle de receitas, despesas e organização financeira pessoal.

## 🎯 Objetivo

Desenvolver uma aplicação simples e funcional para ajudar os usuários a acompanhar sua vida financeira.

## ⚙️ Funcionalidades

- [x] Cadastro de receitas
- [x] Cadastro de despesas
- [x] Cálculo do saldo disponível
- [ ] Relatório mensal
- [ ] Histórico de movimentações

## 💻 Tecnologias utilizadas

- Python
- Git
- GitHub

## 🚀 Como executar

1. Clone este repositório.
2. Instale o Python.
3. Execute o arquivo principal:

```bash
python src/main.py
```
